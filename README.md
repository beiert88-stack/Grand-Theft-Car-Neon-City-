# Neon City Mobile Web

Ein eigenständiger Mobile-Open-World-Prototyp, der direkt im Smartphone-Browser läuft.

## Spielen
Die Dateien auf GitHub hochladen und GitHub Pages aktivieren. Danach kann die Seite auf Android/iPhone geöffnet und über „Zum Startbildschirm hinzufügen“ wie eine App verwendet werden.
